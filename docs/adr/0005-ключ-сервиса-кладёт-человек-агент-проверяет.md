## Контекст

Новые возможности требуют ключей: Auphonic для голоса, Pexels и Pixabay для стоков. Правило мастерской: ключ не просится, не печатается и не пишется агентом или кодом. Владелец в вопросе допускал, что «либо агент сам пойдёт его достанет». Музыку из Epidemic Sound предоставляет их MCP-сервер, а не наш код.

## Решение

Агент открывает человеку нужную страницу сервиса и подсказывает, куда нажать. Человек сам копирует значение в файл окружения. Агент проверяет ключ пробным запросом, не читая значение. Код читает ключи тем же способом, что и распознаватели речи. В профиле хранится только имя переменной. Запрос на другой хост при редиректе уходит без заголовков с ключом. Epidemic подключает агент как MCP-сервер, код треки не скачивает. Для Artlist и Musicbed человек скачивает треки сам по списку.

## Почему

- «Агент сам достанет ключ» отвергнуто: это снимало бы правило, по которому агент не видит ключей. Решено правило не снимать, и это сказано владельцу в интервью.
- Вызов Epidemic из нашего кода отвергнут: доступ у них устроен через MCP-сервер по ключу самого человека.
- Artlist и Musicbed через программу отвергнуты: API для подписчиков нет, это проверено.
- Хранить ключ в профиле или отчёте отвергнуто: профиль уезжает в скилл, отчёт в папку выпуска, ключ там не должен оказаться.

## Последствия

- Копирование ключа вручную — самое хрупкое место для новичка. Мастерская должна вести по шагам и ждать «ключ ответил», иначе возможность не считается подключённой.
- Значение ключа не видно ни в ошибках, ни в логах, поэтому диагностика строится по тому, ответил ли сервис на пробный запрос.
- Каждый сервис платный или по подписке. Нет ключа — нет возможности, и ничего вместо неё не появляется.
- Музыка из Epidemic зависит от того, подключил ли человек их MCP-сервер, и проверяется фактом: сервер отвечает.
