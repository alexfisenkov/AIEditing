## Контекст

Человек должен видеть монтаж на таймлинии рядом с готовым роликом. В коде формат FCPXML до сих пор только читался. DaVinci Resolve официально импортирует FCPXML 1.10 начиная с 18-й версии и бесплатен. Управление Resolve через Python в версии 21.1 доступно только в платной Studio.

## Решение

Рядом с роликом пишется файл таймлинии в формате FCPXML 1.10 и памятка. Открывает его DaVinci Resolve. В форматах с графикой поверх видео человек выбирает один из двух видов: готовая картинка одним клипом, отдельные дорожки звука (голос, звуки, варианты музыки) и маркеры, либо слои по отдельности. Вид подсказывает число камер: одна камера или несколько. В форматах без набора графики таймлиния строится слоями. Без программы мастерская предлагает поставить бесплатный DaVinci и ведёт до «открылась». Если человек не хочет, он получает только готовый ролик и правки по таймкодам, как раньше.

## Почему

- Final Cut отвергнут: владелец проекта убрал его, программа тут не нужна.
- Управление Resolve через Python отвергнуто: оно работает только в Studio, а такой доступ будет у малого числа людей. Это записано в отчёт как вне рамок.
- Только вариант «картинка одним клипом» отвергнут: в форматах без набора графики нет готовой картинки, нужны слои. Только слои тоже не подошли: для однокадровой съёмки и для съёмки с нескольких камер история разная.
- Требовать DaVinci от всех отвергнуто: человек вправе остаться на готовом ролике и правках по таймкодам.

## Последствия

- Перенос вложенных клипов и маркеров из FCPXML 1.10 в DaVinci 21.1 подтверждается только пробным импортом. Если часть не переносится, это фиксируется отдельной записью, а памятка говорит человеку, как есть.
- Слои строятся во времени резки до ускорения. Человек должен поставить скорость сам, по памятке.
- Поддерживается один редактор. Людям с другой программой остаётся ролик и правки по таймкодам.
- Форматом пользуется и набор графики, поэтому изменение формата затронет оба конвейера.
