## Контекст

Нужны вставки из галереи человека под смысл фраз. Пользоваться мастерской будут люди с разными компьютерами, локальные модели сверх уже нужных не допускаются. Работа агента идёт в пределах подписки, лимит может кончиться посреди галереи.

## Решение

Опись хранится текстовыми строками, по одному файлу на вид материала (галерея, архив Instagram, футажи, стоки), и дописывается пачками без перечитывания всего. Технические сведения (дата, ориентацию, длину) снимает код. Смысл (кто, что, где, к каким фразам) описывает агент глазами по листам мелких кадров с номерами, по одной строке на файл. Прогресс сохраняется после каждой пачки. Кандидатов на вставку ищем по словам описи против фраз расшифровки, окончательный выбор делает агент скилла.

## Почему

- Локальная модель для описания и поиск по эмбеддингам отвергнуты: нужны мощный компьютер и дополнительные программы, а всё новое должно работать на любом компьютере без локальных моделей.
- Перечитывание и перезапись всей описи при каждой пачке отвергнуты: для галереи в тысячи файлов это дорого, а оборванный лимитом прогон терял бы работу.
- Поиск по словам принят потому, что он работает везде и объясним: человек видит, по какому слову вставка попала под фразу.

## Последствия

- Качество вставок зависит от того, насколько точно агент описал файл. Два прогона по одной галерее дадут разные описания.
- Поиск не понимает смысл вне слов: перефразированная фраза может не найти подходящий кадр, пока в описи нет нужного слова.
- Описание галереи тратит лимит подписки агента. Большая галерея описывается за несколько заходов.
- Без Pillow лист кадров собирается без цифр: номер равен порядку, нумерованный список печатает команда.
