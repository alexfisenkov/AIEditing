# Архитектура

Решения и их причины — `docs/adr/`, словарь — `CONTEXT.md`. Здесь: из чего сложено и как течёт.

## Две части набора

- **Мастерская** (`skills/aiediting/`: `SKILL.md`, `phases/`, `tools/ae.py`) — интервью, пробный ролик, дашборд, сборка и установка скилла формата. Сама только пробует; ничего не публикует, не загружает, не генерирует.
- **Скилл формата** — собирается из шаблона `templates/format-skill/` плюс нужные части `runtime/` и становится самостоятельным (`run.py`). Мастерская ему больше не нужна.

## Поток данных

1. Интервью → **профиль** (`templates/profiles/*.json`, схема `schema/profile.schema.json`): список шагов `steps` и их `params`.
2. `ae.py build-skill` (`tools/aelib/build.py`, `assemble.py`, `skillmd.py`): профиль + `catalog/*.json` → папка скилла; в неё копируется `runtime/` (всегда `BASE_RUNTIME` из `tools/aelib/catalog.py`, остальное — по шагам профиля), `SKILL.md` собирается из `SKILL.md.tmpl` и кусков `method/*.md` (`skillmd.METHOD_IF`).
3. `run.py edit <видео>` → `runtime/pipelines/run.py::run`: `Context` (`context.py`) проходит шаги в порядке `registry.py::PLAN`.
4. Сначала **план с человеком**: шаги спрашивают через `ctx.ask(ключ, payload)`; ответ даёт approver (`approvals.py` скилла — файловый, останавливает прогон кодом 3 и продолжается по `--answers`). Потом **рендер без остановок** (`render.py::render_piece`): резка → ракурсы → вставки → графика → скорость → звук. В конце отчёт (`report.py`) в папку выпуска.
5. Результат — **выпуск**: видео, `.srt`, отчёт, по выбору — `таймлиния/`, `публикация.md`, `обложки/`, `досъёмка.md`, `музыка-варианты/`.

## Границы модулей

| Пакет | Владеет |
|---|---|
| `runtime/library/` | Библиотека человека: указатель, раскладка, опись (JSONL), правила и запреты, поиск по словам, стоки. Формат описи и порядок поиска путей наружу не выходят |
| `runtime/pipelines/` | Шаги конвейера и `Context`; один шаг — один модуль, регистрация в `registry.py` |
| `runtime/media/` | ffmpeg-операции без решений: резка, вставки, FCPXML, синхронизация, обложки |
| `runtime/asr/` | Распознавание речи (локально и облачные), чтение ключей `secrets.py::read_key` |
| `runtime/services/` | Внешние сервисы голоса; запросы только через `web.py` |
| `runtime/look/`, `runtime/render/` | Разбор кадров/экрана и рендер плашек, анимаций, обложек |
| `skills/aiediting/overlay-kit/` | Набор графики (Remotion): шаблон, `tools/overlay.py`, каталог звуков `template/public/sfx/` |
| `tools/aelib/` | Команды мастерской; одна команда — один модуль `cmd_*.py`, разбор аргументов — `cli.py` |

Набор графики не импортирует `runtime/`, но загружает `runtime/media/fcpxml.py` по пути, дубля нет.

## Договорённости

- Публичный репозиторий: без имён людей и их материалов, без личных путей и значений ключей; проверяет `tests/test_no_reference_names.py`.
- Новое — только по выбору человека и без локальной модели; старые профили собираются и работают как раньше.
- Ключ сервиса человек кладёт сам; в профиле только имя переменной; код и агент ключ не печатают и не просят. Редирект на чужой хост уходит без секретных заголовков (`services/web.py`).
- Тексты для агента (`SKILL.md`, `phases/`, `prompts/`, `references/`, `method/`, `overlay-kit/*.md`) — по-английски; человеку и сообщения об ошибках — по-русски.
- Код: Python 3.9, `from __future__ import annotations`, `typing.List/Dict/Optional`, `.format()`, атомарная запись файлов, подпроцессы без shell, без новых обязательных pip-зависимостей (Pillow и numpy только там, где опциональны). Модуль — одна ответственность, ориентир 60–150 строк.
- Новый шаг: запись в `registry.py::PLAN` и `catalog/steps.json`. Новый `params.<ключ>`: строка в таблице `phases/interview.md` и чтение `ctx.p("<ключ>")` в `pipelines/*.py`. Команда из `phases/*.md` зарегистрирована в `tools/aelib/cli.py`.
- Режим `auto` (без вопросов): ключ вопроса, неизвестный `AutoApprover`, принимается и пишется решением в отчёт.
- Версия — в `runtime/__init__.py`, `SKILL.md` и первой записи `CHANGELOG.md`; меняется одним последним изменением.

## Данные вне репозитория

- Библиотека человека: указатель `~/.aiediting/library.json` (перекрывается `AIEDITING_LIBRARY`); раскладка и поля описи — `runtime/library/paths.py`, `inventory.py`.
- Рабочая папка мастерской (кадры, пробы, дашборд) — `.aiediting-work/` в текущей папке или `AIEDITING_WORK`, см. `tools/aelib/paths.py`.
- Приватное окружение и модели — `~/.aiediting/` (`venv`, `models`, `remotion`); там же `update-check.json` — ответ GitHub о последней версии, не старше суток (`runtime/updates.py`, выключается `AIEDITING_NO_UPDATE_CHECK=1`).
- Ответы знакомства — в `state.js` рабочей папки мастерской (`ae.py intro`, `tools/aelib/intro.py`), переживают `init --fresh` в той же папке; в репозиторий не попадают.
- Рабочие папки графики — `~/.local/share/overlay-kit/`: рендер из облачной папки зависает.
